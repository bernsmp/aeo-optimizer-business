## 🛠️ Development Notes

### Schema Loading
- Schemas are loaded dynamically via `schema-loader.js`
- JSON files in `src/schema/` are loaded and injected into HTML
- FAQ schema is generated from FAQ section HTML

### File Structure
- Static site structure (can be converted to any framework)
- HTML files in `src/pages/`
- Public assets in `public/`
- Styles in `src/styles/` (to be created)

### Deployment
- Can be deployed to any static hosting (Netlify, Vercel, etc.)
- Or converted to any framework (Next.js, Gatsby, etc.)
- Schema files can be served as static JSON

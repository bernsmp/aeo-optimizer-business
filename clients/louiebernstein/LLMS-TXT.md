# llms.txt File

## What This Is
This is a special file that helps AI systems understand your website. It's like a cheat sheet for AI crawlers - telling them who you are, what you do, and where to find important information.

## Where to Add This
Upload this file to the **root** of your website so it's accessible at: `http://louiebernstein.com/llms.txt`

## How to Add It

### Step 1: Create the File
1. Copy the content above (everything between the ``` markers)
2. Create a new text file called `llms.txt`
3. Paste the content into it
4. Save it

### Step 2: Upload to Your Website
1. Log into your website hosting (cPanel, FTP, or your hosting dashboard)
2. Navigate to the **root directory** (usually `public_html` or `www`)
3. Upload `llms.txt` to the root
4. Test it by visiting: `http://louiebernstein.com/llms.txt`

### If You Use WordPress:
- Use an FTP client or File Manager in cPanel
- Upload to the root directory (same level as `wp-config.php`)

### If You Use a Website Builder:
- Most builders have a "File Manager" or "Upload Files" option
- Upload to the root/public directory

## Why This Matters
This file helps AI systems quickly understand your business without having to crawl your entire site. It's like giving AI a quick reference guide, making it more likely they'll cite you correctly.

## Test It
After uploading, visit `http://louiebernstein.com/llms.txt` in your browser. You should see the file contents. If you see a 404 error, the file isn't in the right location.
